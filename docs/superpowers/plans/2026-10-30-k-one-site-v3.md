# K-ONE Site v3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild the K-ONE IT SOLUTIONS website as a light-first "proof in the open" studio site with six service pages, four evidence dossiers, downloadable technical briefs, a circular navigation and a live deployment.

**Architecture:** Astro static pages with a few React islands. Typed TypeScript data files hold services, dossiers and about content. One shared dossier template and one shared service template. Motion is CSS plus IntersectionObserver, with framer-motion only for the radial nav, hero map parallax and tickers. PDFs are generated once with headless Chromium and committed, so the build stays browser-free.

**Tech Stack:** Astro 7, React 19, Tailwind 4, framer-motion 14, lucide icons, Fontsource variable fonts plus Instrument Serif, sharp, Cloudflare Workers static assets.

**Spec:** `docs/superpowers/specs/2026-10-30-k-one-site-v3-design.md`

**Dossier facts:** `docs/research/2026-10-30-dossier-notes.md`

## Global constraints

- No em dashes in copy. Use full stops, commas or colons.
- Light theme is the default. Dark theme remains a saved preference.
- No invented metrics, prices, clients, testimonials or deployments.
- Vigil has no declared licence. Call it "source available", never open source.
- Vigil links use the `develop` branch.
- Status labels must match reality: Vigil and TimeLex are source only, ClearCut and SA-JAS are live alphas.
- Every external link uses `rel="noopener noreferrer"` and a screen-reader note.
- Every motion has a `prefers-reduced-motion` path.
- SA-JAS screenshots are the owner's own assets from the public repository. Demo data only.
- Do not publish the CV or any Mostoeneng Bill work.
- Run `npm run check` and `npm run build` before every commit that changes source.
- Commit in small increments on `feat/site-v3`.

- [ ] **Step 3: Add page transitions and the reveal observer to `Base.astro`**

Add `import { ClientRouter } from 'astro:transitions';` and `<ClientRouter />` in the head. If the import fails after install, check the installed Astro exports and use the current equivalent. Add this before `</body>`:

```html
<script>
  const runReveal = () => {
    const els = document.querySelectorAll<HTMLElement>('[data-reveal]');
    if (window.matchMedia('(prefers-reduced-motion: reduce)').matches) {
      els.forEach((el) => el.classList.add('is-revealed'));
      return;
    }
    const io = new IntersectionObserver((entries) => {
      entries.forEach((entry) => {
        if (entry.isIntersecting) {
          entry.target.classList.add('is-revealed');
          io.unobserve(entry.target);
        }
      });
    }, { threshold: 0.12, rootMargin: '0px 0px -8% 0px' });
    els.forEach((el) => io.observe(el));
  };
  runReveal();
  document.addEventListener('astro:page-load', runReveal);
</script>
```

- [ ] **Step 1: Build `CircularNav.tsx`**

Use `useState`, `useRef`, `useEffect`, `motion`, `AnimatePresence`, `useReducedMotion`. Items: Home `/`, Services `/services/`, Work `/work/`, About `/about/`, Contact `/contact/`. Arc from -168 to -12 degrees at radius 118 (desktop) and 92 (below 640 px, read once with `window.innerWidth`).

Core geometry:

```ts
const radius = compact ? 92 : 118;
const start = -168;
const end = -12;
const step = (end - start) / (items.length - 1);
const x = Math.cos(((start + step * i) * Math.PI) / 180) * radius;
const y = Math.sin(((start + step * i) * Math.PI) / 180) * radius;
```

Behaviour:

- Hidden until `window.scrollY > 480`, and while printing via `print:hidden`.
- Trigger: `aria-expanded`, `aria-controls="quick-nav"`, `aria-label` that changes between "Open quick navigation" and "Close quick navigation".
- Open on click, Enter or Space. Close on Escape, outside click, or link selection. Return focus to the trigger on Escape.
- ArrowRight and ArrowDown move to the next item, ArrowLeft and ArrowUp to the previous, Home and End to the first and last. Focus wraps.
- Focus is contained in the nav while open.
- Labels show on hover and focus with `whitespace-nowrap` tooltips, and each link has an accessible name.
- Reduced motion: animate opacity and scale only, no spring orbit.
- Visual: 56 px trigger, ink background, lime icon, hairline ring, items as 44 px paper discs with cobalt focus ring.

Add a code comment crediting the pattern: `// Pattern inspired by Kaif UI's Circular Navigation Bar (21st.dev), implemented from scratch.`
