# AgentOS working plan: tasks

How to use this list:

- Take the first unticked task. Tasks run strictly in the order listed. A task that touches a file an earlier task also touches starts only after that earlier task is merged, so no two open pull requests ever edit the same lines.
- One task is one pull request on its own branch (`<type>/<short-slug>`, conventional commit messages, per `AGENTS.md`). Never push to `main` and never merge: AgentOS Studio reviews and merges.
- Every pull request ticks its box here and appends one line to `docs/agentos/REPORT.md`.
- Every task that changes code adds or updates tests, and `npm run build` plus every existing test must pass.
- Content only. Do not change layout, page structure, components' markup, styles, colours, fonts, images or animations, and do not add, remove or swap dependencies. Use only facts from `gh repo list konethegreat`, repository READMEs, GitHub releases and the live sites, and name the source in the pull request description.
